#+TITLE: C/C++ LSP

主要就是要告诉 LSP Server Include 和 LD Path，依赖安装方式就各种方式都行了。对于使用 CMake 的项目，可以通过下面命令生成 compile_commands.json：
#+begin_example
  cmake -H. -BDebug -DCMAKE_BUILD_TYPE=Debug -DCMAKE_EXPORT_COMPILE_COMMANDS=YES
#+end_example
